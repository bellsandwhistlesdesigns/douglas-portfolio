Douglas Portfolio

Frontend Web Development | HTML5, CSS3 & JavaScript

Overview

Douglas Portfolio is a personal developer portfolio website designed and hand-coded to showcase software development projects, technical leadership experience, and professional qualifications. The website was developed using HTML5, CSS3, and vanilla JavaScript without relying on frontend frameworks or pre-built website templates.

My Role

  • Website architecture and page structure
  • Semantic HTML development
  • Custom CSS styling and responsive layouts
  • JavaScript interaction and navigation
  • Content organization and presentation
  • GitHub repository management and deployment

Technology Stack

  • HTML5
  • CSS3
  • Vanilla JavaScript
  • Font Awesome icons
  • Git and GitHub
  • GitHub Pages hosting
  • Visual Studio Code

Website Architecture

The portfolio uses a multi-page website architecture with dedicated HTML pages for the homepage, professional resume, and individual project case studies. Shared CSS styles provide consistent typography, colours, headers, footers, navigation, and responsive behaviour throughout the website.

Frontend Development

  • Built the website using semantic HTML elements including header, main, section, navigation, and footer.
  • Developed reusable CSS classes for project cards, buttons, content sections, and navigation elements.
  • Implemented responsive layouts using CSS Flexbox and media queries.
  • Created interactive project carousels with horizontal scrolling and JavaScript navigation controls.
  • Added CSS animations, hover effects, and visual transitions to improve the user experience.

Responsive Design

The website was designed to support desktop, tablet, and mobile viewing. Responsive CSS media queries adjust project card dimensions, typography, and layout behaviour across different screen sizes.

Development Process

Development is managed through Visual Studio Code and GitHub. The website has been progressively improved through updates to its layout, content structure, responsive styling, and project presentation. The portfolio continues to evolve as additional software development projects and case studies are added.

Challenges & Solutions

  • Consistent Styling: Organized CSS into shared and page-specific stylesheets to maintain a consistent appearance.
  • Responsive Project Cards: Used Flexbox, scroll snapping, and media queries to support different screen sizes.
  • Content Organization: Separated software development projects, technical leadership projects, and additional project contributions.
  • Maintainability: Reused existing HTML structures and CSS classes when introducing new project pages.

Outcome

Developed and deployed a functional, responsive, multi-page developer portfolio using fundamental web technologies. The project demonstrates hands-on frontend development, custom styling, JavaScript interactions, version control, and independent website deployment.
